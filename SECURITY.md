# Chính sách bảo mật

## Báo cáo lỗ hổng

Vui lòng **không** mở issue công khai cho lỗ hổng bảo mật. Hãy dùng tính năng
[Private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)
của GitHub (tab **Security → Report a vulnerability**) trên repo này.

Thông tin cần có: phiên bản, mô tả, các bước tái hiện, tác động dự kiến. Không gửi kèm dữ liệu
thật của tổ chức.

Tác giả sẽ phản hồi xác nhận trong vòng 7 ngày và phối hợp công bố sau khi có bản vá.

## Reporting a vulnerability (English)

Please use GitHub private vulnerability reporting instead of public issues. Do not attach real
organisational data.
